This is an Enigma Emulator. More specifically it is an Enigma M4 Emulator. The latest version of Enigma that was in service during WW2. This Emulaotr is a 1:1 replica in terms of functionality. Using this emulator you can learn how Enigma works and the difficulty the 
Allied powers faced in decyphering the ciphers generated by Enigma.

Changelog with regards to Enigma V1.3

Input filtering has been changed so that copy/pasted entries are scrutinized for invalid characters ex. "[" and removed rather then being converted to a valid character as was being done before.

The Input Textbox has been relocated to above the Output Textbox.
